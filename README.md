# Steam Relay Picker

Connect directly to your favorite Steam relays! Created to solve mid-game relay redirections and essentially force a specific server by blocking Steam relay IPs.

Currently, this is only designed specifically for CS2 servers, but should also work with Steam servers in general.

# Requirements

Install .NET Desktop Runtime 10 or greater from Microsoft
https://dotnet.microsoft.com/en-us/download/dotnet/10.0

Only supports windows machines so far (tested on W11 25H2 and .NET Desktop Runtime 10.0.8)

# How to use

1. Refresh the list
2. Select (Checked) the server locations that you don't want to be connected to
3. Press "Confirm Rules" to apply the change

If you want to clear all rules, just unselect everything then confirm the changes.
